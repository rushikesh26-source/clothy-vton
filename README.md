# Clothy AI: Mobile Virtual Try-On (VTON) System

FitSync AI is a zero-hardware, staff-assisted Virtual Try-On web application designed for physical retail stores. It allows store owners to generate highly realistic try-on images for customers directly from a smartphone browser, completely eliminating the need for expensive in-store smart mirrors.

## 🚀 Core Features
* **Zero-Hardware (BYOD):** Runs entirely on the store owner's mobile browser.
* **Real-Time Inventory Validation:** AI generation is strictly tied to live MongoDB stock counts—customers can only try on what is physically available.
* **Cloud-Optimized Delivery:** Integrates the Cloudinary API for high-speed image delivery and lightweight database management.
* **Microservice Architecture:** Utilizes a MERN stack frontend/backend alongside a Python FastAPI server running open-source diffusion models (e.g., CatVTON/IDM-VTON).
